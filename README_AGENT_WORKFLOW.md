# AI-Assisted Team Workflow

1. Clone repository.
2. Read `AGENT_CONTEXT.md`.
3. Read relevant `docs/` files.
4. Use `.agents/rules`, `.agents/workflows`, and `.agents/skills`.
5. Work in a focused feature branch.
6. Implement the smallest correct change.
7. Test/lint/build.
8. Review diff.
9. Update contracts/docs when interfaces change.
10. Commit and open a PR.

Useful workflow playbooks in `.agents/workflows/`:
- `feature.md` (Feature workflow)
- `bugfix.md` (Bugfix workflow)
- `review.md` (Review workflow)
- `integration.md` (Integration workflow)
- `release.md` (Release verification workflow)
