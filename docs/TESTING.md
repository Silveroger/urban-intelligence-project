# Testing Strategy

## Every change
- lint
- type/build checks
- relevant tests
- diff review

## Integration
Test real contract shapes with fixtures.

## GIS
Validate coordinate conversion and map layer behavior.

## Backend
Test validation, geospatial matching, aggregation, persistence, and error cases.

## AI
Test malformed/low-confidence outputs and evidence handling.

## Completion
A feature is done only after verification, not after code generation.
