# Security Rule

- Never print, hardcode, commit, or expose secrets.
- Keep `.env` files out of Git.
- Use `.env.example` for required variable names.
- Validate untrusted API/input data.
- Use least-privilege credentials and API restrictions.
- Do not weaken auth, CORS, or security settings just to make local development work.
- Review new dependencies and external integrations for security implications.
