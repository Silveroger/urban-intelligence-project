# Integration Workflow

1. Read `docs/ARCHITECTURE.md`.
2. Read the relevant `*_CONTRACT.md`.
3. Inspect both producer and consumer.
4. Compare field names, types, IDs, coordinates, timestamps, nullability, and error shapes.
5. Integrate without rewriting unrelated components.
6. Add contract/integration tests.
7. Run lint/build/tests.
8. Document any accepted compatibility decisions.
