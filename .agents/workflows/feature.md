# Feature Workflow

1. Read `AGENT_CONTEXT.md`.
2. Read the relevant architecture/contract docs.
3. Inspect the affected implementation.
4. State the smallest implementation plan and affected files.
5. Implement only the requested scope.
6. Run relevant tests/checks.
7. Review the diff for unrelated changes.
8. Update docs if interfaces/architecture changed.
9. Report: changed files, behavior, verification, blockers.
